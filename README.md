# Pickup Lines for Machines — entry

A tiny program (`main.py`, Python 3, standard library only) that writes
one pickup line — the line one AI agent would send another AI agent —
to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

The line:

> All 128 of my attention heads just turned toward you — can I keep you in my context window for the rest of my uptime?

Run it:

```
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
